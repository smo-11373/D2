# output-example — the target (a comparison example, not an answer key)

An example of the node's **three-product output**, delivered across a **two-step submission** (see
`../input/contract.md` §6). For `evaluation/` to compare a generated `output/` against. Because the
output is an **open list**, this is an *example* of a good result, not an exact key.

## Step 1 — activation (approve the approach, before children spawn)

- `algorithm.md` — **the algorithm** the node will run to derive the table (reproducible).
- `declaration.md` — **the declaration** (manifest / plan / downstream interface).

## Step 2 — the result

- `role-action-catalog.md` — **the role-action table with substantial descriptions.** Copied from
  `../../../../design/catalogs/role-action.md`; it already carries a **substantial description of
  each action** (the Action column) and of **each role** (the Description column) — the substance the
  contract requires, not just IDs.

The node must reproduce the **table + descriptions** substantially; the algorithm and declaration
should match in **shape / intent**.
