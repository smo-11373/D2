# environment/action-aggregate — the inherited, accepted action aggregate (read-only)

The **parent Action-Aggregate node's owned data**, passed down to the Experience node as a **read-only**
input in its contract (`RU-04`/`RU-08`). This is what the UX layout must **cover** — every action here gets
an experience.

`role-action-catalog.md` is the **canonical 8-role / 63-action reference** aggregate (the action-aggregate
test's `output-example`), used as a clean, accepted input so the UX layout is anchored to stable action IDs.
It is **not** to be edited here — to change it, the Experience node **proposes up** to the Action node
(`RU-09`).
