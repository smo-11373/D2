# Open Questions

*Living. Unresolved design questions awaiting resolution, each with enough context to pick up later.*

- **Role layering / "Designer" terminology.** *(High-leverage — governs how every role and action attaches to a layer.)* The baseline uses three overlapping "designer" terms:
  - **Designer** (Phase 1 §2) — primary user of D2; directs D1 evolution (i.e. designs D1, using D2). Seeded as **R-01**.
  - **D1 Designer** (Phase 5 §Item 3) — changes what the product (D0) is designed to be (i.e. designs D0, using D1). Seeded as **R-02**.
  - **"the D2 Designer"** (Phase 5, re: completing D2's own living sets) — appears to mean whoever designs D2 itself.

  These form a self-similar ladder — each layer's "designer" uses that layer's tool to design the layer below — but the naming overlaps. Decide: (a) Is R-01 "Designer" the same as "the D2 Designer," or distinct? (b) Confirm R-02 "D1 Designer" is a separate lower-layer role, not R-01 viewed at a different layer. *(Raised while seeding the roles catalog.)*

- **D0 User as a role.** Phase 6 Item 1 references "D0 users," "D0 user priorities," and "user skill level," but Phase 5's enumerated positions stop at D0 Operator. Decide whether the D0 User is a distinct role from the D0 Operator. *(Raised while seeding the roles catalog.)*
